# Stoneage — Cartão de Referência

```
🪨 STONEAGE — Referência Rápida
─────────────────────────────────────────────

Comandos Slash:
  /stoneage [lite|full|ultra]   Ativar modo compacto
  /stoneage-commit              Mensagem de commit concisa
  /stoneage-review              Code review em 1 linha
  /stoneage-compress <arquivo>  Comprimir arquivo .md/.txt
  /stoneage-stats               Estatísticas de economia
  /stoneage-help                Este cartão

Aliases em Linguagem Natural:
  token economy on/off          Ligar/desligar suíte mestre
  modo pedra / stoneage         Ativar stoneage full
  answer first on/off           Respostas diretas sem preâmbulo
  code only on/off              Apenas bloco de código
  silent tools on/off           Comprimir saídas de terminal
  context trim on/off           Podar saídas volumosas de ferramentas
  session budget on/off         Escala automática por pontuação
  memory prune on/off           Higienizar MEMORY.md

Desativação:
  "stop stoneage" / "modo normal" / "normal mode"

─────────────────────────────────────────────
Níveis de Intensidade:
  lite  → direto, sem enrolação, mantém artigos
  full  → fragmentos OK, sem artigos (padrão)
  ultra → máxima contração, siglas, setas (X → Y)
─────────────────────────────────────────────
```
